# OFM-SmartIrrigationModule

OpenKNX Funktionsmodul für Smart-Irrigation Anwendungsfälle.

## Struktur

- `doc/` Modul-Dokumentation für ETS/OpenKNXproducer
- `src/` Quellcode und OpenKNXproducer Dateien
- `src/Baggages/Help_de/` Kontext-Hilfetexte

## Enthaltene Basisdateien

- `src/SmartIrrigationModule.h`
- `src/SmartIrrigationModule.cpp`
- `src/SmartIrrigation.script.js`
- `src/SmartIrrigation.share.xml`
- `src/ModuleVersionCheck.h`

## Hinweis

Die Version-Makros werden über `versions.h` (OpenKNXproducer) bereitgestellt.
