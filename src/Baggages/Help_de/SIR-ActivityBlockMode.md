# Aktivitätssperre - Modus

Bestimmt, welche Eingangssignale die Aktivitätssperre auslösen:

- **Präsenz ODER Tür:** Eines der beiden Signale genügt zur Aktivierung
- **Präsenz UND Tür:** Beide Signale müssen gleichzeitig aktiv sein
- **Nur Präsenz:** Nur das Präsenz-KO wird ausgewertet
- **Nur Tür:** Nur das Tür-KO wird ausgewertet

**Empfehlung:** "Präsenz ODER Tür" für maximale Sicherheit.
