# Saison aktivieren

Beschränkt die automatische Bewässerung auf einen definierten Zeitraum (Saison).

Außerhalb der Saison werden keine automatischen Bewässerungszyklen gestartet. Das System bleibt aber aktiv und sammelt weiterhin Wetterdaten.

**Hinweis:** Manuelle Bewässerung ist auch außerhalb der Saison möglich.

Bei deaktivierter Saison-Funktion bewässert das System ganzjährig nach Bedarf.
