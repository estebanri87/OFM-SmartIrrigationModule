# Aktivitätssperre - Verzögerung

Definiert die Verzögerung in Sekunden, bevor die Aktivitätssperre wirksam wird.

Nach Erkennung von Aktivität (Präsenz oder Türöffnung) wird die Bewässerung erst nach Ablauf dieser Verzögerung pausiert. So werden kurze Durchgänge ignoriert.

**Wertebereich:** 0-60 Sekunden

**Empfehlung:** 5-10 Sekunden für typische Anwendungen.
