# Aktivitätssperre aktivieren

Aktiviert die temporäre Pausierung der Sprinklerbewässerung bei erkannter Aktivität im Gartenbereich.

Wenn aktiviert, werden Sprinkler-Zonen automatisch pausiert, sobald:
- Präsenz über den entsprechenden KO gemeldet wird
- Eine Tür/Gartenpforte geöffnet wird

Die Aktivitätssperre gilt nur für Sprinkler-Zonen (Zone als "Sprinkler" konfiguriert). Tropfbewässerung läuft weiter.

**Hinweis:** Manuelle Bewässerung übersteuert die Aktivitätssperre.
