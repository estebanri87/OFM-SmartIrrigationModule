# Soak-Zeit (Einsickerzeit)

Zeit in Minuten, die zwischen Bewässerungszyklen gewartet wird, damit das Wasser in den Boden einsickern kann.

Bei schwerem Boden oder Hanglagen kann Wasser oberflächlich ablaufen, bevor es einsickert. Durch Aufteilen der Bewässerung in mehrere kurze Zyklen mit Pausen dazwischen (Soak-Cycles) wird dies verhindert.

**Wertebereich:** 0-120 Minuten (0 = kein Soaking)

**Empfehlung:**
- Sandiger Boden: 0-15 Minuten
- Normaler Boden: 15-30 Minuten
- Schwerer Lehmboden: 30-60 Minuten
- Hanglage: 45-90 Minuten

**Hinweis:** Bei aktiviertem Soaking wird die Bewässerung automatisch auf mehrere Zyklen aufgeteilt (siehe "Max. Bewässerungszyklen").
