# Tank aktivieren

Aktiviert die Tank-/Zisternenverwaltung.

Wenn aktiviert, wird der Füllstand des Wassertanks überwacht. Bei niedrigem Füllstand kann die Bewässerung pausiert oder gestoppt werden.

Das Füllstandssignal wird über das entsprechende KO empfangen (0-100%).

**Hinweis:** Ohne aktivierte Tank-Funktion wird unbegrenztes Wasser angenommen.
