# Zonenwechsel-Verzögerung

Verzögerung in Sekunden zwischen dem Stopp einer Zone und dem Start der nächsten Zone.

Diese Pause ermöglicht:
- Druckausgleich im Bewässerungssystem
- Schonung der Ventile bei schnellen Wechseln
- Vermeidung von Druckspitzen im Leitungsnetz

**Wertebereich:** 0-60 Sekunden

**Empfehlung:** 5-10 Sekunden für typische Systeme mit Magnetventilen.

**Hinweis:** Bei Systemen mit langsamem Druckaufbau kann ein höherer Wert sinnvoll sein.
